# Design reference

[User's Figma file](https://www.figma.com/site/jrIl7inxjGBG49U4rgcAX3/NASA?node-id=0-3)

Figma returned HTTP 403, so the implementation follows the three screenshots
provided in chat: two copies of the login card and one signup card. The starting
page uses the same visual language, with navigation to login and signup.

Shared visual values are defined in `../assets/styles.css`: black background,
red card (#b3220d), white rounded inputs, white text, and black action buttons.
The Figma editor chrome visible around the screenshots is not part of the app.
No native `.fig` file was supplied or generated.
